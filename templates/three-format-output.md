# 三稿输出模板与一致性核对表

复制本模板填充。交付顺序：事实表 → 长文 → 口播稿 → 图文卡片稿 → 一致性核对表。

## 一、事实表（先建，三稿共用编号）

```
| 编号 | 类型 | 原文表述（基准） | 统一表述 |
|---|---|---|---|
| F1 | 数字 | 增长 30% | 增长 30% |
| F2 | 时间 | 2024 全年 | 2024 全年 |
| F3 | 因果 | A 投入导致 B 转化提升 | A→B 转化提升 |
| F4 | 引述 | 「用户最在意稳定性」——产品经理 | 同左，发言人固定 |
```

无可核查事实时，写「素材无可核查事实，跳过本表与一致性核对」。

## 二、长文

```
# 标题

## 小标题 1
正文 3~6 句，段落一屏可读。事实照 F 编号写，不口语化。

## 小标题 2
...

## 小结
一句收束 + 行动建议。
```

## 三、口播稿（60 秒约 240 字）

```
（钩子 3 秒）**你以为 XX，其实……** /

（核心 1）F1 对应内容，口语可写「三成」，但表中标一致。/
（核心 2）F3 对应内容。/

（结尾）一句话总结 + 引导关注。
```

## 四、图文卡片稿（9 张内）

```
[标题卡] 主题一句话
[内容卡 1] F1 对应的一句话
[内容卡 2] F3 对应的一句话
...
[结尾卡] 引导动作
```

## 五、一致性核对表（必做，核心价值）

```
| 编号 | 原文表述 | 长文 | 口播 | 卡片 | 是否一致 |
|---|---|---|---|---|---|
| F1 | 增长 30% | 增长 30% | 三成（口语） | 增长 30% | 一致（口播已标注） |
| F2 | 2024 全年 | 2024 全年 | 去年 | 2024 全年 | 一致（口播注：即 2024） |
| F3 | A→B 转化提升 | A 导致 B 提升 | A 带来 B 提升 | A 提升 B | 一致 |
```

出现红色项（漂移）时，先给统一表述建议再交付：

```
⚠ 漂移项：
- F1：口播「三成多」与长文「30%」不一致 → 统一为「增长 30%」（口播可保留「三成」，表中标注）
- F3：口播误写为「B 导致 A」→ 统一为「A 带来 B 提升」
```

填写约束：
1. 事实表必须先于三稿建立，三稿只引用 F 编号。
2. 一致性表逐编号检查三稿是否都出现、写法是否统一。
3. 口播/卡片的口语化写法只要在表中标注「一致」即允许，但不允许出现第三种写法。
4. 不新增素材外事实；推测类内容不进事实表。
